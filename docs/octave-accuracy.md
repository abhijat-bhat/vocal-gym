# How far to trust the octave checks

Generated by `node scripts/octave-accuracy.js`. The checks are in `octaveChecks` (`src/engine/repertoire.js`); the flags are listed in [octave-review.md](octave-review.md).

**In short:** the checks catch about 36.3% of octave slips planted at random, and when they catch one they nearly always suggest the right fix. How many of the real flags are correct is not known yet: that needs the marked sample below.

## 1. Planted slips (recall)

4000 times, a line the checks leave alone had one swara moved an octave (never its first or last swara). The trials are fixed by a seed, so the numbers repeat.

| | Caught | Of |
| --- | --- | --- |
| All | 36.3% | 4000 |
| Suggested exactly the original back, of those caught | 99.9% | 1453 |
| Moved up | 36.5% | 2003 |
| Moved down | 36.2% | 1997 |
| In a piece of 12 lines or more | 35.8% | 2438 |
| In a shorter piece | 37.1% | 1562 |

Of those caught, the “one swara far from both neighbours” check caught 96.6% and “the same swaras elsewhere” 47.4% (some by both). The rest go unflagged, so a line with no tag is not proof that its octaves are right.

This says nothing about false alarms: a real leap that looks like a slip is flagged all the same.

## 2. Two sources (a small, independent check)

17 lessons exist in both the site and the lesson book with the site’s version in use; 17 lines match swara for swara once octaves are ignored.

| | Lines | Flagged |
| --- | --- | --- |
| The two sources agree on the octaves | 17 | 0 (0.0%) |
| They differ | 0 | 0 (n/a) |

A flag on a line both sources agree on is a false alarm, or a slip they share. Where they differ, 0 of 0 flags suggest exactly the book’s reading. These are short teaching pieces, so the numbers may not hold for the krithis, where most flags are.

## 3. The sample to mark (precision)

This is the number that matters, and it needs a singer or a teacher. Mark each suggestion below right or wrong, then put the answers in `SAMPLE_MARKS` in `scripts/octave-accuracy.js` and run it again.
